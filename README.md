# Irfan HomeCare — Premium Home Healthcare Platform

A production-ready scheduling, real-time consultation, payment, and telemetry web application.

## Core Architecture
- **Backend**: Flask REST API, Celery Workers, Redis, PostgreSQL.
- **Frontend**: React PWA, Tailwind CSS.

## Getting Started
### Running backend
```bash
cd backend
.venv/bin/flask run
```

### Running frontend
```bash
cd apps/web
npm run dev
```
