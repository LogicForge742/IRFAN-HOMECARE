# Changelog

All notable changes to the Irfan HomeCare project will be documented in this file.

## [1.0.0] - 2026-08-01
### Added
- Complete automated unit/integration testing suite for backend and frontend.
- Centralized Analytics and Observability Dashboard.
- Progressive Web App (PWA) supporting offline access and push notifications.
- Kubernetes deployment manifests and Prometheus/Grafana monitoring configs.
- Video session module leveraging WebRTC/Socket.IO signaling.
